# Hacknovate — Build. Break. Innovate.

A cinematic hackathon landing page built specifically as a portfolio/interview project.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger

## Features

- Responsive landing page
- GSAP hero entrance animation
- Floating hero visual
- Scroll-triggered section reveals
- Animated progress line
- Responsive track cards
- CSS marquee
- Reduced-motion fallback

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Interview talking points

I built this project to demonstrate modern frontend development with Next.js, Tailwind CSS and GSAP. The page uses the App Router, a client-side animation component for GSAP, utility-first responsive styling, and ScrollTrigger for scroll-based reveals.
